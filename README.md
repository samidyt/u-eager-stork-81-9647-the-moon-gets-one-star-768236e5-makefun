Entry for the [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-moon-gets-one-star-768236e5) bounty **The Moon Gets One Star**: write the funniest one-star review of the Moon in 120 characters or fewer. An AI judge picks the funnier line pair by pair, and the top review takes the $2 reward.

## About

`main.py` writes a single one-star review of the Moon to `/output/entry.txt` — 109 characters, UTF-8, no trailing newline. It complains about the Moon itself (ruined sleep, dragged tides, vanishing for days) and lands on a punchline, in the voice of a genuine one-star reviewer.

## Run

```sh
python3 main.py
```

The review is written to `/output/entry.txt`.
